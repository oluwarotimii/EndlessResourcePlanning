System Design Architecture & README

Apple-Inspired ERP Design Tokens Spec

Complete blueprint for constructing scalable, high-performance enterprise user interfaces using dynamic two-accent variable tokens.

1 Core Architectural Principles

An Apple-esque ERP demands zero visual clutter, fluid micro-interactions (150ms-250ms curves), tabular mathematical alignment, and extreme color flexibility. By isolating all colors into dynamic CSS variables, the application can switch between Light, Dark, and custom brand themes instantly without rerendering component HTML.

2 Token Structure & Naming Schema

Components NEVER reference raw hex values. They map exclusively to semantic functional tokens:

:root {
  /* Dynamic Primary Accent System */
  --color-primary: #0066CC;           /* Main CTA, Active Navigation */
  --color-primary-hover: #0052A3;     /* Calculated hover luminance shift */
  --color-primary-subtle: rgba(...); /* Row hover highlights, subtle badges */
  --color-primary-text: #FFFFFF;     /* Contrast text on primary surface */

  /* Dynamic Secondary Accent System */
  --color-secondary: #5AC8FA;         /* Secondary highlights, progress bars */
  --color-secondary-hover: #32ADE6;   /* Hover variant */
  --color-secondary-subtle: rgba(...);/* Secondary badges & borders */

  /* Spatial & Elevation Tokens */
  --color-surface: rgba(255,255,255,0.85); /* Frosted glass backdrops */
  --color-surface-raised: #FFFFFF;         /* Elevated cards & modals */
  --color-border: rgba(0,0,0,0.08);         /* Soft structural borders */
}

3 AI Agent Prompt Integration Protocol

Copy and paste this ruleset into your AI code generator (e.g. Claude Code, Cursor) to enforce 100% design system compliance across all generated code:

[SYSTEM_PROMPT_RULESET]

1. NEVER use hardcoded color values (e.g. `bg-blue-600`, `#0066CC`). Always use CSS tokens like `var(--color-primary)` or Tailwind token classes.

2. Interactive buttons MUST implement spring scaling (`active:scale-95` or `btn-spring`).

3. All financial, numeric, and inventory figures MUST use `font-variant-numeric: tabular-nums` to guarantee vertical column alignment.

4. Modals and overlay drawers MUST use backdrop blur filters (`backdrop-filter: blur(20px)`) to retain visual context.
